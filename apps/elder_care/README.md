# 獨居長者照護應用（apps/elder_care）

以 HLK-LD2410B 毫米波雷達為感測來源的照護功能。本目錄只放**應用層規則**：
吃驅動的 snapshot、吐事件，不直接碰硬體，因此可在電腦上以假時鐘測試。

## 檔案

| 檔案 | 用途 |
|---|---|
| `radar_care.py` | 粗粒度照護：存在、久無活動、離床未回、長時間無人、夜間照明 |
| `bed_monitor.py` | 睡眠情境：翻身、坐起、離床、回床、地板停留分級告警 |
| `care_demo.py` | 實機示範（存在／活動／夜燈），直接控 LED |
| `bed_demo.py` | 實機示範＋校準工具（印距離、能量、基線、狀態） |
| `../../tests/test_radar_care.py` | 8 項單元測試 |
| `../../tests/test_bed_monitor.py` | 11 項單元測試 |

測試刻意留在專案根目錄的 `tests/`，這樣 `python -B -m unittest discover -s tests`
一次就能跑完整套件；本目錄放的是可上裝置的應用程式。

## 分層

```text
hardware/ld2410.py        驅動：UART 封包、解析、OUT 腳、snapshot
apps/elder_care/*.py      規則：把 snapshot 變成事件（本目錄）
tasks.py / web_server.py  整合：LED、Web、MQTT（尚未接入）
```

## 功能與事件

`RadarCare.update(snap, hour=None, light=None)`：

| 事件 | 意義 |
|---|---|
| `movement` | 一次活動（60 秒去抖） |
| `wake_up` | 夜間活動，疑似起身 |
| `night_light` | 夜間低光＋活動，建議照明 |
| `inactivity` | 連續無活動（預設 30 分鐘） |
| `bed_exit_overdue` | 離床後未回（預設 10 分鐘） |
| `away_too_long` | 連續無人在房（預設 3 小時） |

`BedMonitor.update(snap)`：

| 事件 | 意義 |
|---|---|
| `turn` | 翻身（能量爆衝、距離幾乎不變） |
| `sit_up` | 坐起（能量爆衝、距離相對基線改變 ≥ 門檻） |
| `leave_bed` | 距離帶連續空 5 秒 |
| `return_bed` | 回到距離帶並持續 3 秒 |
| `floor_notice` | 停留地板高度 30 秒 |
| `floor_alert` | 2 分鐘 |
| `floor_critical` | 10 分鐘 |

## 安裝位置與距離帶（重點）

安裝原則：**用距離把床與其他空間分開**，讓「躺床／站／地板」落在三個互不重疊的帶。

天花板正對床中心（2.4–2.7 m）效果最好。以下為一般家庭（床面離地 60 cm）的估算：

| 情境 | 軀幹離地 | 到天花板的徑向距離 | 設定 |
|---|---|---|---|
| 站在床邊 | 120–130 cm | 120–130 cm | 不屬於任何帶 |
| 躺在床 | 75–80 cm | 165–185 cm | `RADAR_BED_MIN_CM`／`MAX_CM` |
| 躺在地板 | 15–20 cm | 225–245 cm | `RADAR_BED_FLOOR_MIN_CM`／`MAX_CM` |

量到的是**軀幹**（反射最強），不是床面；距離是徑向距離，不是離地高度。

## 地板告警：寧可多報，不可漏報

長時間停留在地板本身就值得關注。採三級升級，每級每次事件只發一次：

| 等級 | 預設 | 建議動作 |
|---|---|---|
| `floor_notice` | 30 秒 | 本地輕提示（燈／語音） |
| `floor_alert` | 2 分鐘 | 通知照護者（Web／MQTT／蜂鳴） |
| `floor_critical` | 10 分鐘 | 升級通報 |

`monitor.acknowledge()` 讓照護者確認後停止本輪升級；人離開地板帶即自動重新武裝。

## 校準步驟

```python
exec(open('apps/elder_care/bed_demo.py').read())
run(90)
```

依序：站床邊 20 秒 → 躺床 20 秒 → 躺地板 30 秒 → 回床，記下三段距離並填入 `config.py`。
地板距離差若小於 40 cm，改用天花板正上方安裝。

## 參數設定策略

2026-11-23 起，**S2 Mini（GPIO36／38／40）的 UART 命令通道已恢復**：可直接用驅動的
`read_params()`／`write_params()`／`set_resolution()` 讀寫參數，不必只靠手機。
原廠 BLE APP 仍適合在現場快速查看與微調：

- App：HLKRadarTool，<https://www.hlktech.com/Mobile/App/12.html>（Android／iOS）
- 廣播名：`HLK-LD2410B_xxxx`；預設密碼 `HiLink`；一次只能連一支手機
- 可調：最大運動／靜止距離門、每個距離門的靈敏度、無人延時、解析度、工程模式

### UART 命令的價值（何時值得回頭修）

| 能力 | 現況 |
|---|---|

已對過原廠範例並有單元測試，屆時只需修好線路即可使用。

## 限制（不可對外宣稱的功能）

- **不是跌倒偵測**：只能判斷「長時間停留在特定高度」；跌在床上、沙發或視野外皆看不到。
- **不是呼吸監測**：模組只有微動能量，沒有呼吸率或波形。
- 只給徑向距離，無高度與角度；無法還原姿勢。
- 被子、寵物、風扇、窗簾會造成誤報，需以門檻與確認機制管理。
- 無影像、無穿戴，仍應讓長輩與家屬知情。
